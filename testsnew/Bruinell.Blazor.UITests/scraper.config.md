# Scraper Config

The Blazor sample's pages, recorded with the Scraper for page objects (the `scrape-pages` skill).
Start the sample first: `dotnet run --project samples/Bruinell.Samples.Blazor.App --urls http://localhost:5180`
(from the Bruinell root).
