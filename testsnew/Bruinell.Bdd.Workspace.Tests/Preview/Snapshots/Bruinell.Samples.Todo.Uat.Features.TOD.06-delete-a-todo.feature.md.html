Scenario TOD.06.1 Delete asks for confirmation

  1. GivenI am on the Todo List page
  2. Andthe server also has todos
    Title
    Sell the sofa
  3. WhenI tap Sync
  4. ThenTodos should have todo "Sell the sofa"
  5. WhenI open the todo "Sell the sofa"
  6. ThenI should be on the Todo Detail page
  7. WhenI tap Delete
  8. Thenthe dialog should ask "Delete todo?"
  9. WhenI choose "Cancel" in the dialog
  10. Thenno dialog should be shown
