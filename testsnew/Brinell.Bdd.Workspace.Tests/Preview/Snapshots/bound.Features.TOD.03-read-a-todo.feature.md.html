Scenario TOD.03.1 Tapping a row opens its detail with all its fields

  1. GivenI am on the Todo List page
  2. Andthe server also has todos
    TitleStatusDueDateNotes
    Plan the partyInProgress+3dInvite the neighbours
  3. WhenI tap Sync
  4. ThenTodos should have todo "Plan the party"
  5. WhenI open the todo "Plan the party"
  6. ThenI should be on the Todo Detail page
  7. AndTitle should equal "Plan the party"
  8. AndStatus should show status "In progress"
  9. AndNotes should equal "Invite the neighbours"
  10. AndDue should exist
  11. AndCreated should exist
  12. AndUpdated should exist
  13. AndSync State should equal "Synced"
