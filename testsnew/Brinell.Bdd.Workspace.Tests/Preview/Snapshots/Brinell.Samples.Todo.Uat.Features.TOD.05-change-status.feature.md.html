@TOD.05.1 @maui @web @status

Scenario TOD.05.1 Next cycles the status to Done, and it is saved

  1. GivenI am on the Todo List page
  2. WhenI tap Add
  3. ThenI should be on the Todo Edit page
  4. WhenI set Title to "Plan the sprint"
  5. AndI advance Status to "Done"
  6. ThenStatus should show status "Done"
  7. WhenI tap Save
  8. ThenI should be on the Todo List page
  9. AndTodos should have todo "Plan the sprint"
  10. Andthe database should have todos
    TitleStatus
    Plan the sprintDone
