# Display Controls

**Source of truth:** `srcnew/Brinell.Maui/Controls/Display/`

## Controls

| Control | Interfaces | MAUI Control |
|---------|-----------|-------------|
| `MauiLabelControl` | `ITextControlObject` | `Label` |
| `MauiImageControl` | `IControlObject` | `Image` |
| `MauiBadgeControl` | `ITextControlObject` | Badge overlays |

Display controls are read-only. They implement text/visibility queries but not input actions.
