@TOD.04.1 @maui @web @edit

Scenario TOD.04.1 Edit opens the form filled with the current values

  1. GivenI am on the Todo List page
  2. Andthe server also has todos
    TitleStatusDueDate
    Renew insuranceInProgress+20d
  3. WhenI tap Sync
  4. ThenTodos should have todo "Renew insurance"
  5. WhenI open the todo "Renew insurance"
  6. ThenI should be on the Todo Detail page
  7. WhenI tap Edit
  8. ThenI should be on the Todo Edit page
  9. AndTitle should equal "Renew insurance"
  10. AndStatus should show status "In progress"
  11. AndHas Due Date should be checked
  12. AndDue Date should be enabled
  13. WhenI tap Cancel
  14. ThenI should be on the Todo Detail page

@TOD.04.2 @smoke @maui @web @edit

Scenario TOD.04.2 Saving updates the detail and the list and marks the todo pending

  1. GivenI am on the Todo List page
  2. Andthe server also has todos
    Title
    Call mum
  3. WhenI tap Sync
  4. ThenTodos should have todo "Call mum"
  5. WhenI open the todo "Call mum"
  6. ThenI should be on the Todo Detail page
  7. WhenI tap Edit
  8. ThenI should be on the Todo Edit page
  9. WhenI set Title to "Call dad"
  10. AndI tap Save
  11. ThenI should be on the Todo Detail page
  12. AndTitle should equal "Call dad"
  13. AndSync State should equal "Waiting to sync"
  14. WhenI tap Back
  15. ThenI should be on the Todo List page
  16. AndTodos should have todo "Call dad"
  17. AndTodos should not have todo "Call mum"
  18. Andthe todo "Call dad" should be waiting to sync
  19. Andthe database should have todos
    TitleSyncState
    Call dadPending
