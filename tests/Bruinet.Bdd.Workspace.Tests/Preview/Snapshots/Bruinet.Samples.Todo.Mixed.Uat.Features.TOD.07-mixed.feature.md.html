Apps apps.md: Daan and Gus on Windows, Finn in a browser. Each step runs on the app of the user it names.

@TOD.07.11 @mixed @sync

Scenario TOD.07.11 A todo Daan creates on Windows reaches Finn's browser

  1. GivenDaan is on the Todo List page
  2. AndFinn is on the Todo List page
  3. WhenDaan taps Add
  4. ThenDaan should be on the Todo Edit page
  5. WhenDaan sets Title to "Pack for the trip"
  6. AndDaan taps Save
  7. ThenDaan should be on the Todo List page
  8. WhenDaan taps Sync
  9. Thenthe server should have received the todo "Pack for the trip" from Daan
  10. AndFinn should be on the Todo List page
  11. AndTodos should not have todo "Pack for the trip"
  12. WhenFinn taps Sync
  13. ThenTodos should have todo "Pack for the trip"

@TOD.07.14 @mixed @sync

Scenario TOD.07.14 Finn's browser, offline, gets Daan's todo once it is back online

  1. GivenDaan is on the Todo List page
  2. AndFinn is on the Todo List page
  3. AndFinn is offline
  4. ThenSync should be disabled
  5. WhenDaan taps Add
  6. ThenDaan should be on the Todo Edit page
  7. WhenDaan sets Title to "Renew the insurance"
  8. AndDaan taps Save
  9. ThenDaan should be on the Todo List page
  10. WhenDaan taps Sync
  11. Thenthe server should have received the todo "Renew the insurance" from Daan
  12. WhenFinn is back online
  13. ThenSync should be enabled
  14. WhenFinn taps Sync
  15. ThenTodos should have todo "Renew the insurance"
