Scenario TOD.08.1 A server error on sync shows the Error state with Retry; local data is kept

  1. GivenI am on the Todo List page
  2. Andthe server also has todos
    Title
    Pay the bills
  3. WhenI tap Sync
  4. ThenTodos should have todo "Pay the bills"
  5. Giventhe server fails with status 500
  6. WhenI tap Sync
  7. Thenthe list should show the Error state
  8. AndError Message should contain "server had a problem"
  9. AndLast Sync should equal "Sync failed"
  10. AndRetry should be enabled
  11. Andthe database should have todos
    TitleSyncState
    Pay the billsSynced
  12. Whenthe server recovers
  13. AndI tap Retry
  14. Thenthe list should show the Content state
  15. AndTodos should have todo "Pay the bills"
