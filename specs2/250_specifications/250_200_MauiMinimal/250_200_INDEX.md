## Overview

This module defines the minimal set of interfaces and classes needed to support MAUI Button and Entry controls. It establishes the foundation patterns that will be extended for all other controls.

## Key Design Principles

1. **Controls can be scoped to Pages OR Views (Containers)**
2. **Views can be scoped to Pages OR other Views OR Lists**
3. **Scope is the element finder, not the context**
4. **All controls implement IControlObject**

## Hierarchy Overview

```
IElementScope<AppiumElement>
├── IMauiTestContext (root scope - driver)
├── IMauiPageObject (page scope)  
├── IMauiContainerControl (view scope)
└── IMauiListItemControl (list item scope)

IControlObject
├── IClickableControl
│   └── ButtonControl
├── ITextControl
│   └── IEditableTextControl
│       └── EntryControl
└── IContainerControl
    ├── View (custom containers)
    └── IListItemControl (items in CollectionView)
```
