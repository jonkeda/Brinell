# Brinell BDD for VS Code

Brinell feature and step files (`*.feature.md`, `*.steps.md`) and suite configs, with the same
language server as the Visual Studio extension:
- the gate's diagnostics as you type;
- completion, hover, go to definition, find references, quick fixes and rename;
- a Scenario Preview;
- running and debugging scenarios from Test Explorer, with step breakpoints.

It needs the .NET 10 runtime, and the C# extension to debug.

The guide is `docs/guides/vscode-extension.md` in the Brinell repository.
