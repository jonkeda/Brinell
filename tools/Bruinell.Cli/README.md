# bruinell

Bruinell's command line: the Scraper (record or explore an app, draft and verify page objects),
test data and scenario checks, feature-file previews, ControlObject generation, and the language
and MCP servers the IDE extensions and agents start.

```powershell
dotnet tool install -g Bruinell.Cli
bruinell --help
bruinell scrape status
bruinell data validate
```

Every command, its options and exit codes:
[docs/run/cli.md](https://github.com/exact-mobile-apps/test-tooling/blob/main/docs/run/cli.md).
