# Spec Status

The previous spec files are preserved in `docs2/specs`. New active specs should
be added here with a status.

## Status Values

- Proposed: accepted for discussion, not yet committed.
- Active: currently being implemented.
- Implemented: behavior exists and is covered by tests/docs.
- Superseded: replaced by another design.
- Archived: historical reference only.
