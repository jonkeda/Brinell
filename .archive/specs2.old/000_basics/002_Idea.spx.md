# idea Unified Cross-Platform UI Testing
- **overview**: One API to test them all—write UI tests once and run them across WPF, MAUI, HTML, and Stride applications
- **rationale**: Modern .NET applications span multiple platforms and UI frameworks. Test writers shouldn't need to learn different automation tools for each platform. A unified abstraction over platform-specific drivers (Appium, Selenium, Playwright) lets teams share test patterns, page objects, and expertise across their entire product portfolio.
- **outcome**: Reduced test maintenance burden, consistent test patterns across platforms, faster onboarding for test writers, and the ability to reuse page object designs when applications migrate between frameworks
- **status**: accepted
- **priority**: high
- **effort**: large
- **stakeholders**: Framework Team, Test Writers, Platform Maintainers, QA Teams
- **tags**: cross-platform, ui-testing, abstraction, page-object, automation
