# 220.004 FlaUI

**Block Type:** EXT (External Dependency)  
**ID:** 220.004  
**Title:** FlaUI Integration  
**Status:** Draft  
**Version:** 1.0

---

## 1. Overview

FlaUI is the automation library used by `Brinell.Wpf` for testing WPF and WinForms desktop applications on Windows. It wraps Microsoft UI Automation (UIA) with a clean .NET API.

> **Note:** Code snippets in this document are illustrative examples. Final implementations may vary.

### Integration Identity

- **Package:** `Brinell.Wpf`
- **NuGet Dependencies:** `FlaUI.Core`, `FlaUI.UIA3`
- **Minimum Version:** 4.0.0
- **Namespace:** `FlaUI.Core`, `FlaUI.UIA3`

---

## 2. Purpose

FlaUI provides:

1. **Windows Desktop Automation** — WPF, WinForms, Win32, UWP
2. **UI Automation Wrapper** — Clean API over Microsoft UIA
3. **Element Finding** — AutomationId, Name, ClassName, ControlType
4. **Pattern Support** — Invoke, Value, Selection, Toggle, etc.
5. **Active Development** — Modern .NET support, maintained library

## 3. Key Types Used

### 3.1 Core Types

```csharp
// Application and automation
Application                // Launched or attached application
UIA3Automation             // UI Automation provider (UIA3)
UIA2Automation             // Legacy UI Automation (UIA2)

// Window and elements
Window                     // Application window
AutomationElement          // UI element wrapper
```

### 3.2 Element Types

```csharp
// Strongly-typed control wrappers

ComboBox                   // Dropdown/combo control
ListBox                    // List control
DataGrid                   // Data grid control
Menu                       // Menu control
Tab                        // Tab control
Tree                       // Tree view control
Label                      // Label/text block
```

### 3.3 Locator Strategies

```csharp
// ConditionFactory for element finding
cf.ByAutomationId(string id)        // AutomationId property
cf.ByName(string name)              // Name property
cf.ByClassName(string className)    // ClassName property
cf.ByControlType(ControlType type)  // Control type
cf.ByText(string text)              // Text content
cf.ByHelpText(string text)          // Help text

// Combining conditions
cf.ByAutomationId("btn").And(cf.ByName("Submit"))
cf.ByClassName("Button").Or(cf.ByClassName("RepeatButton"))
```

## 4. Brinell Integration

### 4.1 IWpfTestContext

The `IWpfTestContext` interface wraps FlaUI operations:

```csharp
public interface IWpfTestContext : ITestContext
{
    // FlaUI-specific access
    Application Application { get; }
    UIA3Automation Automation { get; }
    Window MainWindow { get; }
    
    // Element finding
    AutomationElement FindElement(Locator locator);
    AutomationElement? TryFindElement(Locator locator);
    IReadOnlyList<AutomationElement> FindElements(Locator locator);
}
```

### 4.2 Locator Mapping

Brinell's `Locator` class maps to FlaUI conditions:

| Brinell Locator | FlaUI Condition |
|-----------------|-----------------|
| `LocatorStrategy.AutomationId` | `cf.ByAutomationId()` |
| `LocatorStrategy.Name` | `cf.ByName()` |
| `LocatorStrategy.ClassName` | `cf.ByClassName()` |
| `LocatorStrategy.XPath` | Tree traversal (manual) |
| `LocatorStrategy.ControlType` | `cf.ByControlType()` |

### 4.3 Element Property Mapping

| Brinell Property | FlaUI Property |
|------------------|----------------|
| `IsVisible()` | `element.IsOffscreen == false` |
| `IsEnabled()` | `element.IsEnabled` |
| `GetText()` | `element.Name` or `element.AsTextBox().Text` |
| `GetAttribute(name)` | `element.Properties.GetPropertyValue()` |

## 5. Application Launch

### 5.1 Launch New Application

```csharp
// Launch application
var app = Application.Launch(@"C:\path\to\app.exe");

// Launch with arguments
var app = Application.Launch(new ProcessStartInfo
{
    FileName = @"C:\path\to\app.exe",
    Arguments = "--debug"
});

// Wait for main window
using var automation = new UIA3Automation();
var mainWindow = app.GetMainWindow(automation, TimeSpan.FromSeconds(10));
```

### 5.2 Attach to Running Application

```csharp
// Attach by process name
var app = Application.Attach("MyApp");

var app = Application.Attach(processId);

var app = Application.AttachOrLaunch(new ProcessStartInfo(@"C:\path\to\app.exe"));
```

## 6. Element Finding

### 6.1 Basic Finding

```csharp
using var automation = new UIA3Automation();
var mainWindow = app.GetMainWindow(automation);
var cf = mainWindow.ConditionFactory;

// Find by AutomationId
var button = mainWindow.FindFirstDescendant(cf.ByAutomationId("SubmitButton"));

// Find by Name
var label = mainWindow.FindFirstDescendant(cf.ByName("Welcome"));

// Find by ClassName
var textBox = mainWindow.FindFirstDescendant(cf.ByClassName("TextBox"));

// Find by ControlType
var buttons = mainWindow.FindAllDescendants(cf.ByControlType(ControlType.Button));
```

### 6.2 Scoped Finding

```csharp
// Find within container
var panel = mainWindow.FindFirstDescendant(cf.ByAutomationId("LoginPanel"));
var usernameBox = panel.FindFirstDescendant(cf.ByAutomationId("UsernameTextBox"));
```

### 6.3 Combined Conditions

```csharp
// AND condition
var submitButton = mainWindow.FindFirstDescendant(
    cf.ByAutomationId("SubmitButton").And(cf.ByControlType(ControlType.Button))
);

// OR condition  
var anyButton = mainWindow.FindFirstDescendant(
    cf.ByName("OK").Or(cf.ByName("Cancel"))
);
```

## 7. Element Interaction

### 7.1 Clicking

```csharp
// Using patterns
var button = mainWindow.FindFirstDescendant(cf.ByAutomationId("Submit")).AsButton();
button.Invoke();  // Uses InvokePattern

// Or click at center
button.Click();

// Double click
button.DoubleClick();

// Right click
button.RightClick();
```

### 7.2 Text Entry

```csharp
var textBox = mainWindow.FindFirstDescendant(cf.ByAutomationId("Username")).AsTextBox();

// Clear and enter text
textBox.Text = "";
textBox.Enter("testuser");

// Or using patterns
textBox.Patterns.Value.Pattern.SetValue("testuser");
```

### 7.3 Selection

```csharp
// ComboBox
var combo = mainWindow.FindFirstDescendant(cf.ByAutomationId("CountryPicker")).AsComboBox();
combo.Select("United States");
var selected = combo.SelectedItem?.Text;

// ListBox
var list = mainWindow.FindFirstDescendant(cf.ByAutomationId("ItemList")).AsListBox();
list.Select(2);  // By index
list.Select("Item Name");  // By text
```

### 7.4 Toggle

```csharp
var checkBox = mainWindow.FindFirstDescendant(cf.ByAutomationId("RememberMe")).AsCheckBox();

// Get state
bool isChecked = checkBox.IsChecked ?? false;

// Set state
checkBox.IsChecked = true;

// Toggle
checkBox.Toggle();
```

## 8. Waiting

### 8.1 Retry Mechanism

```csharp
// FlaUI Retry helper
var element = Retry.WhileNull(
    () => mainWindow.FindFirstDescendant(cf.ByAutomationId("DynamicElement")),
    TimeSpan.FromSeconds(10)
);

// Wait for condition
Retry.WhileFalse(
    () => element.IsEnabled,
    TimeSpan.FromSeconds(5)
);

// Wait for element to disappear
Retry.WhileNotNull(
    () => mainWindow.FindFirstDescendant(cf.ByAutomationId("LoadingSpinner")),
    TimeSpan.FromSeconds(30)
);
```

### 8.2 Custom Wait

```csharp
// Wait for window
var window = Retry.WhileNull(
    () => app.GetAllTopLevelWindows(automation)
              .FirstOrDefault(w => w.Title == "Settings"),
    TimeSpan.FromSeconds(10)
);
```

## 10. WPF vs WinForms Considerations

| Aspect | WPF | WinForms |
|--------|-----|----------|
| AutomationId | Set via `AutomationProperties.AutomationId` | Control `Name` property |
| Control types | Rich control type support | Basic control types |
| Custom controls | Usually expose automation | May need custom patterns |
| Performance | Generally good | Good |

### 10.1 WPF AutomationId Setup

```xml
<!-- XAML -->
<Button AutomationProperties.AutomationId="SubmitButton" Content="Submit"/>
<TextBox AutomationProperties.AutomationId="UsernameEntry"/>
```

### 10.2 WinForms Accessibility

```csharp
// C# - WinForms
button1.AccessibleName = "SubmitButton";
textBox1.AccessibleName = "UsernameEntry";
```

## 11. Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Element not found | Missing AutomationId | Add AutomationId to XAML |
| Stale reference | Window/element closed | Re-find element |
| Pattern not supported | Control doesn't expose pattern | Use alternative approach |
| Slow performance | Too many FindAll calls | Use more specific queries |
| Access denied | UAC/elevated process | Run tests elevated |

## 12. UIA2 vs UIA3

| Feature | UIA2 | UIA3 |
|---------|------|------|
| .NET Support | .NET Framework | .NET Framework & .NET Core/.NET 5+ |
| Performance | Slower | Faster |
| Compatibility | Legacy apps | Modern apps |
| Recommendation | Legacy only | **Use this** |

```csharp
// Prefer UIA3
using var automation = new UIA3Automation();

// Only use UIA2 for legacy compatibility
using var automation = new UIA2Automation();
```
