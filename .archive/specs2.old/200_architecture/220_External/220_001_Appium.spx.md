# 220.001 Appium

**Block Type:** EXT (External Dependency)  
**ID:** 220.001  
**Title:** Appium Integration  
**Status:** Draft  
**Version:** 1.0

---

## 1. Overview

Appium is the automation driver used by `Brinell.Maui` for testing .NET MAUI applications on Android, iOS, and Windows platforms.

> **Note:** Code snippets in this document are illustrative examples. Final implementations may vary.

### Integration Identity

- **Package:** `Brinell.Maui`
- **NuGet Dependency:** `Appium.WebDriver`
- **Minimum Version:** 5.0.0
- **Namespace:** `OpenQA.Selenium.Appium`

---

## 2. Purpose

Appium provides:

1. **Cross-Platform Mobile Automation** — Single API for Android and iOS
2. **Element Finding** — Locate UI elements by accessibility ID, XPath, class name
3. **Gestures** — Touch, swipe, scroll, pinch, zoom
4. **App Lifecycle** — Install, launch, reset, terminate apps

## 3. Key Types Used

### 3.1 Driver Types

```csharp
// Core driver types from Appium.WebDriver
AppiumDriver              // Base driver for all platforms
AndroidDriver             // Android-specific driver
IOSDriver                 // iOS-specific driver
WindowsDriver             // Windows-specific driver (WinAppDriver)
```

### 3.2 Element Types

```csharp
// Element types
AppiumElement             // UI element wrapper
AppiumWebElement          // Web element in hybrid apps
```

### 3.3 Locator Strategies

```csharp
// MobileBy locator strategies
MobileBy.AccessibilityId(string id)    // AutomationId / content-desc
MobileBy.Id(string id)                  // Resource ID (Android)
MobileBy.XPath(string xpath)            // XPath expression
MobileBy.ClassName(string className)    // UI class name
MobileBy.Name(string name)              // Element name
MobileBy.AndroidUIAutomator(string)     // Android UiAutomator2 selector
MobileBy.IosClassChain(string)          // iOS class chain
MobileBy.IosNsPredicate(string)         // iOS NS predicate
```

## 4. Brinell Integration

### 4.1 IMauiTestContext

The `IMauiTestContext` interface wraps Appium driver operations:

```csharp
public interface IMauiTestContext : ITestContext
{
    // Expose driver for advanced scenarios
    AppiumDriver Driver { get; }
    
    // Element finding (abstracts MobileBy usage)
    AppiumElement FindElement(Locator locator);
    AppiumElement? TryFindElement(Locator locator);
    IReadOnlyList<AppiumElement> FindElements(Locator locator);
}
```

### 4.2 Locator Mapping

Brinell's `Locator` class maps to Appium's `MobileBy`:

| Brinell Locator | Appium MobileBy |
|-----------------|-----------------|
| `LocatorStrategy.AutomationId` | `MobileBy.AccessibilityId()` |
| `LocatorStrategy.XPath` | `MobileBy.XPath()` |
| `LocatorStrategy.ClassName` | `MobileBy.ClassName()` |
| `LocatorStrategy.Name` | `MobileBy.Name()` |

### 4.3 Element Property Mapping

| Brinell Property | Appium Property |
|------------------|-----------------|
| `IsVisible()` | `element.Displayed` |
| `IsEnabled()` | `element.Enabled` |
| `GetText()` | `element.Text` |
| `GetAttribute(name)` | `element.GetAttribute(name)` |

## 5. Server Requirements

### 5.1 Appium Server

Tests require a running Appium server:

```bash
# Install Appium
npm install -g appium

# Install drivers
appium driver install uiautomator2  # Android
appium driver install xcuitest      # iOS
appium driver install windows       # Windows (WinAppDriver)

# Start server
appium --address 127.0.0.1 --port 4723
```

### 5.2 Platform-Specific Setup

**Android:**
- Android SDK installed
- `ANDROID_HOME` environment variable set
- Device or emulator running
- USB debugging enabled (physical device)

**iOS:**
- macOS with Xcode installed
- iOS Simulator or physical device
- WebDriverAgent configured

**Windows:**
- WinAppDriver installed
- Developer Mode enabled

## 6. Capabilities Configuration

### 6.1 Android Capabilities

```csharp
var options = new AppiumOptions();
options.AutomationName = "UiAutomator2";
options.PlatformName = "Android";
options.DeviceName = "emulator-5554";
options.App = "/path/to/app.apk";
// Or for installed app:
options.AddAdditionalAppiumOption("appPackage", "com.example.app");
options.AddAdditionalAppiumOption("appActivity", ".MainActivity");
```

### 6.2 iOS Capabilities

```csharp
var options = new AppiumOptions();
options.AutomationName = "XCUITest";
options.PlatformName = "iOS";
options.DeviceName = "iPhone 14";
options.PlatformVersion = "16.0";
options.App = "/path/to/app.app";
```

### 6.3 Windows Capabilities

```csharp
var options = new AppiumOptions();
options.AutomationName = "Windows";
options.PlatformName = "Windows";
options.App = "com.example.app_xyz!App";  // Package family name
// Or path to exe:
options.App = @"C:\path\to\app.exe";
```

## 7. Common Operations

### 7.1 Element Interaction

```csharp
// Find and click
var element = driver.FindElement(MobileBy.AccessibilityId("LoginButton"));
element.Click();

// Enter text
var entry = driver.FindElement(MobileBy.AccessibilityId("UsernameEntry"));
entry.Clear();
entry.SendKeys("testuser");

// Get text
var label = driver.FindElement(MobileBy.AccessibilityId("WelcomeLabel"));
string text = label.Text;
```

### 7.2 Gestures

```csharp
// Tap at coordinates
var finger = new PointerInputDevice(PointerKind.Touch, "finger");
var tap = new ActionSequence(finger);
tap.AddAction(finger.CreatePointerMove(element, 0, 0, TimeSpan.Zero));
tap.AddAction(finger.CreatePointerDown(MouseButton.Left));
tap.AddAction(finger.CreatePointerUp(MouseButton.Left));
driver.PerformActions(new[] { tap });

// Swipe
// ... gesture sequences
```

### 7.3 App Lifecycle

```csharp
driver.ResetApp();           // Reset to initial state
driver.CloseApp();           // Close without uninstall
driver.LaunchApp();          // Launch again
driver.TerminateApp("com.example.app");
driver.ActivateApp("com.example.app");
```

## 8. Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Connection refused | Server not running | Start Appium server |
| Element not found | Timing issue | Add explicit wait |
| Stale element | Page changed | Re-find element |
| App not installed | Wrong path | Verify app path/package |
| Permission denied | Missing capabilities | Add required permissions |
