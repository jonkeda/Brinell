## Overview

Level 0 Foundation specifications define the core abstractions that all controls and platform implementations depend on. These specifications must be complete before implementing any controls.

> **Key Principle:** Foundation is complete. Controls extend, never modify.

### Generic Type Design

All interfaces use a single `TElement` type parameter for the platform's native element type:

| Platform | TElement | Example |
|----------|----------|---------|
| MAUI | `AppiumElement` | `IControlObject<AppiumElement>` |
| Blazor | `IWebElement` | `IControlObject<IWebElement>` |
| WPF | `AutomationElement` | `IControlObject<AutomationElement>` |

Base classes add `TContext` or `TScope` for implementation convenience:
- `ControlBase<TElement, TScope>` — scope is parent page/container
- `PageObjectBase<TElement, TContext>` — context is test context
- `ContainerBase<TElement, TScope>` — scope is parent page/container

## Core Interfaces

### Element Scope Hierarchy

```
IElementScope                          ← Non-generic, untyped
    └── IElementScope<TElement>        ← Generic element finding
            ├── ITestContext<TElement> ← Driver-level scope
            ├── IPageObject<TElement>  ← Page delegates to context
            └── IContainerControl<TElement> ← Container scoped search
```

### Platform Narrowing Pattern

```csharp
// Interfaces narrow via inheritance
IMauiTestContext : ITestContext<AppiumElement>, IMauiElementScope
IMauiPageObject : IPageObject<AppiumElement>, IMauiElementScope
IMauiContainerControl : IContainerControl<AppiumElement>, IMauiElementScope

// Platform aliases for base classes
MauiControlBase = ControlBase<AppiumElement, IMauiElementScope>
MauiPageObjectBase = PageObjectBase<AppiumElement, IMauiTestContext>
MauiContainerBase = ContainerBase<AppiumElement, IMauiElementScope>
```

## Validation Checklist

Level 0 is complete when:

- [x] All interfaces defined with complete members
- [x] Generic `TElement` parameter used for typed element finding
- [x] `IElementScope<TElement>` defines common finding methods
- [x] Platform interfaces narrow via inheritance (not parallel methods)
- [x] Base classes use `TElement + TContext/TScope`
- [x] Platform type aliases defined (MauiControlBase, etc.)
- [x] Constructor pattern: `(scope, locator)` not `(context, locator, page)`
- [ ] MAUI base class hierarchy complete
- [ ] Blazor base class hierarchy complete
- [ ] WPF base class hierarchy complete
- [ ] Platform contexts defined
- [x] Nullable skip pattern documented
- [ ] Template method pattern documented
- [ ] Logging integration documented
- [ ] Timeout inheritance documented
